# 호호책방(book_clinic) 기능 정의서 — Web(운영관리) · PWA(학생)

- 작성일: 2026-10-13
- 작성 근거: 소스 코드 현재 상태(컨트롤러·서비스·매퍼·템플릿·JS)와 `docs/` 기존 문서. 코드 주석의 정책 결정(날짜 표기)을 그대로 반영했다.

  다만 Web/PWA 기능과 맞닿는 지점은 **「앱 연동 경계」** 로 표시만 해 두었다.
- 상태 표기: ✅ 구현 완료 / ⚠️ 부분 구현 또는 확인 필요 / ❌ 미구현(준비 중)

## 2. 공통 정책

| ID | 항목 | 정의 |
|---|---|---|
| C-01 | 직원 인증 | Spring Security 폼 로그인(`/login`). 계정 ID + 비밀번호(사용자별 salt 해시 비교). 성공 시 기본 이동 `/admin/book-data`, 세션 만료로 튕긴 경우 원래 요청한 페이지로 복귀. 로그아웃 시 `/login`. |
| C-02 | 센터 범위(스코프) | 모든 관리자 조회·처리는 **로그인 직원의 소속 센터**로 고정된다. 요청 본문으로 대상 학생을 지정하는 처리(예약 대리 등록/취소, 퇴실, 일지 저장 등)는 `CenterAccessGuard`가 "내 센터 학생인지"를 매번 재검증한다(없는 학생 404, 타 센터 학생 403). |
| C-03 | 본사 권한 | 센터코드 `PUS001` = 본사. 마스터 도서 편집·엑셀 일괄 등록·QR 카드 출력은 본사 전용(화면에서 제어). 권장도서 순위 **변경**(저장·적용·삭제)은 서버가 본사 여부를 검증한다. 조회·엑셀은 전 센터 허용. |
| C-04 | 학생 인증 | 학생증 QR(앱 ID 또는 시리얼 번호) → `HttpSession`에 `studentId` 저장. 이후 화면·API는 세션 값만 신뢰하고 URL/본문의 `studentId`는 세션과 일치할 때만 유효. |
| C-05 | 단일 활성 세션 | 학생별 "유효 세션"은 1개. 다른 기기에서 새로 로그인하거나 직원이 퇴실 처리하면 이전 기기는 다음 요청(또는 문제풀이 중 주기적 세션 확인)에서 강제 로그아웃. 인메모리 저장소(서버 재시작 시 초기화, 단일 인스턴스 전제). |
| C-06 | CSRF | `XSRF-TOKEN` 쿠키 + 헤더 방식. 학생 화면 일부 API와 앱 연동 경로는 예외 처리됨. |
| C-07 | 삭제·이력 | 도서·실물도서·문제·권장순위 초안·스케줄 버전은 삭제 시 `_del` 테이블로 이관하고(수정 시 UPDATE 스냅샷 로그) 도서·실물도서·문제는 복구 가능. 순위 초안 삭제는 복구 미지원. |
| C-08 | 학년 코드 | 클리닉 학년 코드 `01~07` = 초1~초6, 중등. 학생의 `clinic_grade_key`(없으면 올패스 `grade_key`를 변환해 최초 1회 채움)로 추천·레벨을 계산. 유치원(5·6·7세)은 초1 수준으로 매핑. 입회 시 클리닉 코드↔올패스 코드 상호 변환. |
| C-09 | 재고 모델 | 실물 도서(item)는 **(bcode+센터)당 1행 + 수량 카운터**: 보유 `qty`, 대여 `loaned_qty`, 분실/훼손 `lost_qty`. **가용 재고 = qty − loaned_qty − lost_qty**. 대여·반납은 원자적 UPDATE로 처리. |
| C-10 | 예약·이용권 | 회차(slot) 예약 시 **이용권 1회 즉시 차감**, 취소 시 복구(학생·학부모 취소는 회차 시작 24시간 전까지, 직원 대리 취소는 상시). 출석·노쇼로 소진된 횟수는 복구하지 않음. 하루 최대 4회차 예약. 정원 확인과 증가는 단일 조건부 UPDATE로 처리(초과 예약 방지). 이용권 유효기간은 첫 예약일부터 90일(시작일 포함). |
| C-11 | 예약 필수 | 오늘 예약(예약됨/출석)이 없으면 학생 로그인·입실 불가. 입실은 회차 시작 10분 전 ~ 회차 종료 사이에만 허용. |
| C-12 | 시간 기준 | 모든 날짜 판정은 KST. |
| C-13 | 실시간 미러링 | 입실·퇴실·예약·채점 결과는 SQL 반영 후 Firestore로 미러링. Firestore 쓰기 실패는 로그만 남기고 원 트랜잭션은 영향받지 않음. |
| C-14 | 이미지 저장 | 표지·카드·워크시트는 가비아 이미지 호스팅(FTP)에 저장(미설정 시 로컬 폴백). 표지 `{contentId}.png`, 카드 `cards/`, 워크시트 `worksheets/`. |

## 3. Web(운영관리) 기능 정의

### 3-1. W-01 도서 데이터 관리 — `/admin/book-data` ✅

- 접근: 로그인 직원 전원. **본사**는 마스터 도서 편집, **지점**은 마스터 읽기 전용 + 우리 센터 하위 도서 관리.
- 구성: 도서 목록 / 도서 정보 / 문제 출제 3패널 단일 화면.
- 관련 API: `/book/*`, `/question/*`, `/book/image`, `/book/card-image`, `/book/worksheet-image`

| ID | 기능 | 상세 동작 | 규칙·제약 |
|---|---|---|---|
| W-01-01 | 도서 목록 조회 | 학년·분류·사용여부 필터 + 상세 필터(저자·장르·키워드), 초기화/적용 | 검색 조건: 제목·저자·장르·학년·키워드·분류·상태(사용중/절판) |
| W-01-02 | 학년별 목록 엑셀 | 학년별 시트(번호·도서명·저자·학년), 인쇄 설정(제목행 반복·A4 맞춤) | 파일명 `학년별 도서 목록.xlsx` |
| W-01-03 | 신규 도서 등록 (본사) | 도서 정보 폼 입력 후 저장 → 생성된 contentId로 이어서 문제 저장 가능 | 비본사는 같은 버튼이 "+ 우리 센터 도서 등록"(하위 도서)으로 바뀜 |
| W-01-04 | 도서 정보 편집 (본사) | 도서명, 표지 이미지(변경/삭제), 저자, 출판사, 권장학년, 분류(교과연계·학년필독·권장도서·기관추천·인증수상작 — 단일 선택), 장르(코드), 해시태그, 독서 예상 시간(10~50분, 5분 단위), 난이도(상/중/하), 도서 소개, 사용중/절판 | 분류별 부가정보: 교과연계→연계교과 / 기관추천→추천기관 / 인증수상작→수상명 (분류가 바뀌면 이전 부가정보 정리). **문제가 등록되지 않은 도서는 "사용중"으로 변경 불가.** 표지 파일명이 contentId라 **도서 저장 후** 업로드 가능. 일부 필드만 보내는 부분 수정(상태 토글)은 분류 정보를 지우지 않음 |
| W-01-05 | 워크시트 등록·삭제 | 이미지 또는 PDF 업로드, 삭제 | 책당 1개(교체 가능). 등록돼 있어야 모니터링의 출력 아이콘 노출. PDF는 원본 그대로 저장, 출력 시 PDF 한 장으로 병합 |
| W-01-06 | 수집 카드 등록·삭제 | 카드 이미지 업로드, 삭제 | 책당 1장. 미등록 도서는 기본 카드 이미지로 폴백 |
| W-01-07 | 도서 삭제 · 복구 | 목록에서 다중 선택 삭제, "삭제 도서함" 모달에서 복구 | 삭제 시 연결된 실물 도서·문제까지 일괄 `_del` 이관(저장 프로시저). 복구 시 원본 테이블로 복원 |
| W-01-08 | 엑셀 일괄 등록/수정 (본사) | ① 템플릿 다운로드(기존 도서 전체, 학년별 시트, 분류·장르·난이도·학년 드롭다운, A열 content_id 잠금) ② 업로드 → 사전 확인(신규/수정/변경없음 건수) ③ 구간별 반영(진행률 표시) | A열 content_id 있으면 UPDATE(**바뀐 값이 있을 때만**), 없으면 INSERT. 헤더명 기준 파싱(열 순서 무관). 빈 칸=그대로 유지. 한글 코드명→코드값 변환, 해시태그 `#a #b`→`a,b` 정규화 |
| W-01-09 | 하위 도서(센터 보유 도서) 관리 (지점) | 우리 센터 도서 등록/수정(제목·출판사·키워드)/삭제/복구, 지점 전용 표지 | 실물 도서 식별자 bcode는 숫자 UUID(18자리) 자동 발급. 삭제는 우리 센터 보유분만 이관(타 센터 영향 없음). 지점 표지는 마스터 표지를 덮어쓰지 않음 |

### 3-5. W-05 운영 스케줄 — `/admin/operation/schedule` ✅

- 접근: 로그인 직원(센터 고정).
- 관련 API: `/admin/operation/schedule/*`
- 개념: **요일 규칙(버전) + 특정일 예외 → 회차(slot_instance) 실체화**. 예약이 붙는 대상은 요일 규칙이 아니라 실체화된 "N월 N일 N회차"이다.

| ID | 기능 | 상세 동작 | 규칙·제약 |
|---|---|---|---|
| W-05-01 | 요일별 스케줄 조회 | 월~일 탭, 요일별 운영/휴무, 운영시간, 회차 목록 | 저장된 적 없는 요일은 "휴무 + 기본값"으로 항상 7개 반환 |
| W-05-02 | 요일 설정 | 운영/휴무 토글, 운영 시작·종료시각, 회차 기본 시간(30/40/50/60분, 기본 50), 최대 예약 인원(기본 10, 1~200), 회차 자동 생성 | 종료시각 > 시작시각 |
| W-05-03 | 회차 관리 | 회차별 시작·종료시각, 예약 가능 인원, 삭제 (드래그 정렬), 스케줄 복사 | 회차는 운영시간 안, 서로 겹치지 않음, 최소 1개. **회차 번호는 서버가 시작시각 순으로 재부여.** 휴무 요일은 운영시간·회차를 비움 |
| W-05-04 | 적용 시작일 지정 저장 | 적용 시작일 선택 또는 **즉시 적용**(=오늘) 후 월~일 전체 저장 | 저장은 항상 새 **버전(effective_from)** 생성. 같은 시작일 재저장은 덮어쓰기(원본은 `_del`). 조회는 "기준일 이하 중 최신 버전". 저장 직후 해당 요일을 예약 오픈 기간(30일) 안에서 재실체화 |
| W-05-05 | 스케줄 변경 예약 이력 | 버전 카드(이전/운영 중/예정), 버전별 주간 전체 구성 확인 | 종료일은 다음 버전 시작일−1일로 계산. **예정 버전 삭제 가능**(그 기간은 이전 버전 규칙으로 복귀). 수정 API 없음(재저장으로 덮어쓰기) |
| W-05-06 | 특정일 예외 등록 | 기간(시작~종료) + 유형 + 사유(≤200자). 유형 3종 ↓ | 지난 날짜 등록 불가. 종료일 ≥ 시작일 |
| | ├ 휴무 | 기간 전체 휴무 | — |
| | ├ 운영시간 변경 | 그 기간의 운영 시작·종료시각과 **그날 회차를 확정** | 회차는 새 운영시간 안, 겹침 없음, 인원 범위 검증. 회차 미지정 시 새 시간대 안에 온전히 들어가는 기존 회차만 유지(**원래 회차 번호 유지**) |
| | └ 운영회차 변경 | 특정 회차를 마감하거나 정원만 변경 | **하루만 지정 가능.** 휴무·운영시간 변경과 배타적이지 않음(기간 휴무 안의 하루에 얹을 수 있음) |
| W-05-07 | 예외 목록 · 삭제 | 등록된 예외 목록(끝난 지 얼마 안 된 것 포함) 확인, 삭제 | 삭제 시 요일 규칙대로 회차 복구. **수정 API 없음 → 삭제 후 재등록.** "오늘 일정 보기"로 예외가 적용된 결과를 읽기 전용 확인 |
| W-05-08 | 예약 보호 | 예약이 걸린 기간은 예외 **등록·삭제 모두 차단**하고 문제 날짜를 안내 | 이미 예약한 학생의 시간이 말없이 바뀌는 것 방지. 엔진도 예약 있는 날짜는 건너뛰고 로그 기록 |
| W-05-09 | 회차 실체화 우선순위 | 휴무 > 운영시간 변경 > 요일 규칙, 그 위에 회차 변경을 덧칠 | 배치로 매일 재실체화(7장) |

## 4. PWA(학생) 기능 정의

### 4-0. 전체 흐름

```
[공용 출석체크 기기]                     [학생 개인 기기]
 입실(QR) ──▶ 읽을 책 확인(+자동 추천)
    │                                   로그인(QR/앱ID) ──▶ 메인(추천 도서)
    │                                          │
    │                                   문제 풀기 ──▶ 결과 ──▶ (다음 단계 버튼들)
    │                                          │
 책 추천(QR) ◀── 다음 책 ────────────────  완료 화면 ──▶ 책 추천받기 / 여권 작성(로그아웃)
 퇴실(QR)
```

- 입실·책 추천·퇴실은 **출석체크 기기에서만**, 문제풀이는 **학생 개인 기기에서만** 한다(공용 기기에서 학습까지 이어지지 않도록 분리).
- 개인 기기 홈의 "책 추천받기"(완료 화면)는 심화 게이트를 적용한 추천 경로이다.

### 4-1. P-01 런처 / P-02 설치

| ID | 기능 | 상세 | 상태 |
|---|---|---|---|
| P-01-01 | 기기 용도 선택 | `/launch`에서 **문제풀이 / 출석체크** 중 선택 → 브라우저 localStorage(`hohobook.appMode`)에 저장, 이후 선택 화면 없이 바로 해당 모드로 진입 | ✅ (dev 프로파일은 매번 선택 화면 표시) |

## 5. 업무 규칙 상세

### 5-1. 도서 추천 규칙 (`ClinicService.recommendBook`)

호출 시점: 출석체크 입실 시(읽던 책 없을 때), 출석체크 "책 추천", 개인 기기 완료 화면의 "책 추천받기". **멱등**이다.

| 순서 | 규칙 |
|---|---|
| 1 | 이미 추천받은 **읽는 중(PENDING) 책이 있으면 그대로 반환** (재대여가 필요하면 재대여) |
| 2 | **이어 읽기**: 지난번 다 못 읽고 퇴실한 책(HOLD)이 있으면 새 책보다 먼저 되살림(재고 있을 때). 재고 0이면 포기하고 다음 규칙으로 |
| 3 | **심화 게이트**(개인 기기·출석체크 추천 경로에 적용): 직전 완독 책의 심화(qlevel=02)를 **오늘 안에 1회 이상** 제출하지 않았으면 추천 거부("심화 문제를 먼저 풀어야 다음 책을 받을 수 있어요."). 통과 조건: 완독 이력 없음 / 직전 완독일이 오늘이 아님 / 그 책에 심화 문항 없음 / 심화 제출 1회 이상. 직원의 "책 교체"는 게이트 미적용 |
| 4 | 이전에 다 읽은 책을 **반납**하고, 살아있는 홀딩은 **폐기**(유효 홀딩은 학생당 최대 1건) |
| 5 | 후보 선택: **권장도서 순위(올해·학생 클리닉 학년·적용 중 초안) 순서대로**, ① 사용 중(state=Y) 도서 ② 학생 센터에 **가용 재고**가 있는 판본 ③ 이 학생에게 **추천된 적 없는** 도서(content 기준 — 다른 판본으로 같은 책 재추천 방지, 폐기된 홀딩은 제외 대상 아님) |
| 6 | 후보가 없으면 **한 단계 위 학년부터 순차 확장**(최대 중등) |
| 7 | 고른 판본을 **원자적으로 재고 확보**(실패 시 그 판본 제외하고 다음 후보). 성공하면 대여 이력 생성 + 추천 이력(PENDING) 기록 + 입실 처리 + "문제 푸는 중" 기준점 초기화 |
| — | 분류·장르 중복 회피는 **없다**(순위표 자체가 분류가 연달아 나오지 않게 섞여 있음). **하루 추천 권수 상한 없음**(2026-09-14 폐지). 후보 소진 시 "추천할 수 있는 도서가 더 이상 없습니다." |

### 5-2. 채점 · 등급 · 점수 (`ClinicService.submitQuiz`)

| 항목 | 규칙 |
|---|---|
| 채점 | 서버가 `문항별 선택값`을 해당 난이도(state=S) 정답과 대조. 첫 시도에서 **미제출 문항은 오답(선택값 0)** 으로 기록(빈 제출로 뱃지 중복 획득 방지). 재제출에서 다시 내지 않은 문항은 직전 정오답을 이어받음 |
| 합격선 | 기본 문제 전체 문항의 **2/3 올림** (12문항→8, 15문항→10). **심화는 합격선 없음**(풀기만 하면 완료) |
| 등급(기본) | 만점 = **KING(정독왕)** / 합격선 이상~만점 미만 = **FRIEND(정독 완료)** / 합격선 미만 = **RETRY(완독 — 재도전 필요)** |
| 첫 제출 | 합격/불합격 무관하게 추천 상태를 **DONE(완독)** 으로 기록(불합격이어도 다음 입실 시 다음 책을 받음). 처음 점수 = 최종 점수 |
| 재제출 반영 | **재도전(전체 다시 풀기)** 과 **틀린 문제 다시 풀기 1회차**만 최종 점수·등급·뱃지에 반영. 점수는 높을 때만, 등급은 **오르기만**(RETRY→FRIEND→KING). 2회차부터는 즉시 채점 모드이며 점수·등급·뱃지 불변 |
| 점수 표기 | 모니터링·일지·결과 어디서나 **재제출 결과가 곧 점수**(처음=최종 동일 값 유지) |
| 이미 합격한 책 재제출 | 완독 권수·레벨 불변, 카드 재지급 없음 |
| 심화 | 완독/등급/레벨 처리 없이 채점·풀이 이력·뱃지만. 심화 재도전 없음 — 만점이 아니면 점수와 무관하게(0점 포함) "틀린 문제 다시 풀기"만 열림 |
| 부수 기록 | 풀이 이력(`quiz_answer_log`: 문항, 선택, 정오, 제출모드 FIRST/RETRY/WRONG_ONLY), 독서일지 상세(읽은 책·독서 시간·점수), 모니터링 즉시 동기화(채점 시점에 "결과" 상태로 전환) |

### 5-3. 완료/결과 화면 단계별 버튼 (홈 완료 화면 = 결과 화면 동일 규칙)

| 단계 | 상태 | 표시 버튼 | 다음 책 추천 버튼 |
|---|---|---|---|
| 1 | 완독 (기본 합격선 미달, RETRY) | 결과: "다시 읽으러 가기"(로그아웃) → 재진입 후 홈: **정독 문제 풀기**(전체 재도전) | 숨김 |
| 2 | 정독 완료 (FRIEND) | **틀린 문제 다시 풀기**(기본). 전부 맞히면 → **심화 문제 풀기** | 심화 게이트 통과 & 풀 심화 없을 때만 |
| 3 | 정독왕 (KING) | **심화 문제 풀기** | 풀 심화 문항이 없을 때만 |
| 4 | 심화 완료 (심화 만점 아님, 0점 포함) | **틀린 문제 다시 풀기**(심화). 전부 맞히면 → **여권 작성하기** | 숨김 |
| 5 | 심화왕 (심화 만점) | **여권 작성하기**(로그아웃) | 숨김 (다음 책은 출석체크 기기에서) |

※ 재도전(전체 다시 풀기)은 1단계에만 있다. 4·5단계의 "여권 작성하기"는 종이 독서여권을 쓰러 가는 행동이라 앱 화면이 아닌 로그아웃 처리이다.

### 5-4. 보상 — 뱃지 · 카드

| 항목 | 규칙 |
|---|---|
| 뱃지 (책당 기본 1개 + 심화 1개, **첫 시도 결과로 확정**) | 기본: 불합격=**완독**(1) / 합격=**정독 완료**(2) / 만점=**정독왕**(3). 심화: 풀면 **문해력 챌린저**(4) / 만점 **문해력 챔피언**(5) |
| 뱃지 상향 | 재제출로 등급이 오르면 기존 기본 뱃지를 지우고 상위 뱃지로 교체(내려가지 않음). 심화도 챌린저→챔피언만 상향 |
| 도서 카드 | **책당 1장, 기본 문제 첫 제출 시 합격/불합격 무관** 지급(재도전·재제출은 지급 없음, 이미 받은 카드는 결과 화면에 계속 표시) |
| 레어/스페셜 카드 | 일반 카드가 **10장 단위(10·20·30…)** 가 되는 순간 레어 카드 지급 + 결과 화면 "숨겨진 보물 발견! 선생님께 카드를 받아요!" + **모니터링에 "스페셜 카드 지급" 알림**(직원이 실물 카드 교환). 시스템은 진행도/달성 표시까지 |
| 오프라인 연계 | 스페셜 카드·종이 여권은 현장 수령/작성 — 시스템은 안내만 |

### 5-5. 레벨

| 항목 | 규칙 |
|---|---|
| 레벨 범위 | 1~12 (만렙 12, 칭호 예: GRADE{n} Master) |
| 레벨업 기준 | **완독(DONE) 권수 전체**(책 학년 무관) ÷ 학생 학년별 필요 권수. 레벨 = 완독 권수 / 필요 권수 + 1 |
| 학년별 필요 권수 | 초1·초2 = 8권 / 초3 = 5권 / 초4~초6 = 4권. 단계명: 입문(초1)·성장(초2)·탐구(초3)·심화(초4)·통찰(초5)·마스터(초6). 중등은 규칙 없음 → 레벨 1·진행률 0 |
| 진행률 | 현재 레벨 구간 내 완독 비율, 다음 레벨까지 남은 권수(만렙 0) |
| 독서탐험(연간 목표 칸) | 초1·초2 96 / 초3 60 / 초4~중등 50 (올해 완독 권수 기준, 결과 응답에 포함) |
| 캐릭터 | 초1~초3만 학년 전용 이미지, 나머지는 기본 |
| 첫 제출만 반영 | 재도전·틀린 문제 재제출은 권수 불변 (`levelGained` = 첫 제출 여부) |

### 5-6. 입실 · 퇴실 · 대여 수명주기

| 시점 | 처리 |
|---|---|
| 입실 | 예약 필수·시간대 검증 → 그날 예약 전부 출석 전환 → 세션(ENTERED) 생성 → 일지 헤더 생성 → 모니터링 입실 전환. 이용권은 **예약 시점에 이미 차감**되어 입실에서는 차감하지 않음 |
| 책 대여 | 추천 확정과 동시에 대여(판본 단위). 완독해도 반납하지 않음(재도전 대비) |
| 퇴실 (학생 QR / 직원 처리) | 학생 유효 세션 즉시 무효화 → 세션 종료 → **대여 반납**(완독 여부 무관) → 읽던 책을 **홀딩(HOLD)** 으로 전환(쪽수 기록 여부와 무관, 완독한 책은 대상 아님) → 일지 하원 시각 기록(직원 보정값 보존) |
| 재입실 | 읽던 책이 있으면 같은 판본을 **재대여**(재고 없으면 대여 없이 표시) |
| 다음 책 추천 시 | 이전 책 반납, 홀딩 폐기 |
| 퇴실 복구(직원) | 세션 상태만 되돌림 |
| 하루 여러 회차 | 퇴실 후에도 **퇴실 시각 이후 새로 시작하는 회차**의 이용 시간대면 출석체크 재입실 허용 |
