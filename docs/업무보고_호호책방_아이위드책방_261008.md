# 호호책방 · 아이위드 책방 업무 보고

- 작성일: 2026-10-08
- 대상: book_clinic(호호책방 서버·관리자 웹·학생 PWA), i-with 책방(Flutter 앱)

## 1. 개요

호호책방 독서 클리닉은 센터 학생에게 권장도서를 추천하고, 문제풀이와 채점 결과에 따라 레벨·뱃지로 보상하는 서비스입니다. book_clinic이 데이터와 API를 제공하고, i-with 앱의 책방 메뉴가 이를 호출해 학부모에게 예약, 정독 결과, 이용권 결제를 제공합니다.

## 2. 담당 업무

- **book_clinic (서버·웹)**: 도서·문제 관리, 권장도서 순위, 도서 추천과 서버 채점, 학생 PWA, 운영 스케줄·예약, 실시간 모니터링, 독서일지, 이니시스 결제·이용권·환불, 앱 연동 API, 독서 결과 발송, SSO 인증, DB 설계 및 문서화
- **i-with 책방 (Flutter)**: 책방 메인, 정독 결과(그래프·차트), 예약하기, 이용권 결제·내역·환불, 서재 화면과 서버 데이터 연동

## 3. 진행 현황

- **book_clinic**: 6/5 착수 후 65회 커밋. 핵심 기능은 모두 구현되었고 현재는 디테일 수정과 실결제 전환 준비 단계입니다. (Java 약 2.2만 줄, 화면 35개)
- **i-with 책방**: 9/9 착수 후 11회 커밋. 메인, 정독 결과, 예약, 이용권 결제 화면의 UI와 데이터 연동을 마쳤고, 서재 화면은 작업 중입니다. (Dart 약 7,300줄)
- **결제**: 일시불 결제, 환불, 12회권 이용권(예약 시 차감, 첫 예약일부터 90일)은 완료되었으나 현재 이니시스 테스트 상점으로 동작합니다. 자동결제는 이용권 정책과 맞지 않아 청구를 꺼둔 상태입니다.

| 영역 | 상태 |
|---|---|
| 추천·문제풀이·학생 PWA·모니터링·예약 | 완료 |
| 일시불 결제·환불·이용권 | 완료 (테스트 상점) |
| 앱 책방 메인·정독 결과·예약·결제 | 완료 |
| 앱 서재 화면 | 작업 중 |
| 자동결제 | 보류 (방향 결정 필요) |
| 레벨/뱃지 관리, 학생 성장 분석 화면 | 미착수 |

## 4. 남은 작업

1. **실결제 전환**: 자동결제 방식 결정(일시불만 오픈 / 잔여 2회 이하 자동충전), 12회권 환불 규정 확정, 이니시스 실상점 발급, 운영 설정·키 교체, 실카드 소액 검증
2. **앱**: 서재 화면 완성, 정독 결과 더미 데이터 제거, 실결제 기준 결제 흐름 검증
3. **서버·웹**: 레벨/뱃지 관리와 학생 성장 분석 화면, 정답 노출 보안 및 도서 반납 정책 점검, 핵심 로직 테스트 보강, 문서 최신화

## 5. 앞으로의 역할

- 호호책방 서버·관리자 웹·학생 PWA와 i-with 책방 앱의 개발·유지보수를 담당하고, 서버 API와 앱 화면을 함께 맞춥니다.
- 결제·이용권 영역의 기술 담당으로 실결제 전환과 오픈 후 결제 이상 건 대응을 맡습니다.
- 오픈 이후에는 안정화와 피드백 반영을 거쳐 미구현 관리자 화면과 자동충전 등 기능 확장을 진행합니다.
