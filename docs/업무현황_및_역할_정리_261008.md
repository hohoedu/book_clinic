## 4. 앞으로 이 프로젝트에서 나의 역할

> ⚠️ 아래는 지금까지의 담당 범위와 남은 작업을 바탕으로 정리한 **제안안**입니다. 실제 팀 구성·합의된 역할에 맞게 수정해 주세요.

### 4-1. 역할 정의

- **호호책방 서버·API·관리자 웹·학생 PWA의 개발과 유지보수 책임자**
- **i-with 앱 안의 책방 메뉴(Flutter) 개발 담당** — 서버 API와 앱 화면을 양쪽에서 맞추는 연결 고리
- **결제·이용권 영역의 기술 담당** — 이니시스 연동, 이용권 규칙, 환불, 정합성(결제 이상 건) 관리

### 4-2. 단계별 할 일

| 단계 | 기간(제안) | 주요 업무 |
|---|---|---|
| ① 오픈 준비 | 즉시 ~ 실결제 전환 | 자동결제 방향 결정 지원(옵션별 개발량·리스크 설명), 실상점 전환, 소액 실결제 검증, 서재 화면 마무리 |
| ② 안정화 | 오픈 직후 | 결제 이상 건·예약·모니터링 운영 대응, 버그 수정, 사용자 피드백 반영 |
| ③ 기능 확장 | 이후 | 레벨/뱃지 관리·학생 성장 분석 화면, 자동충전(B안), 알림(알림톡/FCM) 확대 |
| ④ 품질·문서 | 상시 | 핵심 로직 테스트 보강, DB 명세·API 명세·운영 매뉴얼 최신화, 배포·백업 절차 정리 |

### 4-3. 협의가 필요한 사항

1. 자동결제 방식(A/B/C)과 12회권 환불 규정 — 기획·운영 측 결정 필요
2. 이니시스 실상점 발급 일정 — 외부 일정에 따라 오픈이 좌우됨
