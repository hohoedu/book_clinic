# 학생증 QR 카드 디자인 파일

학생정보 화면 → "QR 카드 출력"이 배경으로 깔아 인쇄하는 카드 디자인 이미지입니다.

| 파일 | 용도 |
|---|---|
| `front.png` | 카드 앞면 — QR·지점명·ID가 이 위에 얹힙니다 |
| `back.png` | 카드 뒷면 — 가변정보 없이 디자인만 인쇄 |

- 규격: **CR-80(ISO ID-1) 가로 85.60 x 53.98mm @ 600dpi = 2022 x 1275px**
- 두 파일이 없으면 인쇄 화면이 배경 없이(= 선인쇄 원판 오버프린트 모드로) 동작합니다.

## 교체 방법

```
./docs/tools/psd2card.sh 앞면.png 뒷면.png     # 앞/뒷면 입력 포맷은 달라도 됨 (PSD·PNG·JPEG 등)
./docs/tools/psd2card.sh --back 뒷면.png       # 뒷면만 교체
```

원본 비율이 카드 비율(1.5858 : 1)과 다르면 스크립트가 경고합니다. 현재 시안은 2.1% 차이라
늘려 맞추고 있습니다 — 정확한 비율로 다시 받으면 왜곡 없이 들어갑니다.

## 가변정보 좌표

`static/js/operation/student-info.js` 의 `.qr` / `.center-name` / `.serial` 규칙에서 조정합니다.
전부 **요소 중심** 기준 mm 값이며, 현재 값은 시안과 완성 목업에서 실측한 것입니다.

| 요소 | 중심 좌표 | 크기 | 시안 위치 |
|---|---|---|---|
| QR | (25.6mm, 21.4mm) | 23 x 23mm | 좌상단 흰 둥근박스 정중앙 |
| 지점명 | (24.9mm, 41.7mm) | 4mm bold | 좌하단 연녹색 박스 안 |
| ID | (64.5mm, 32.8mm) | 3.4mm | 우측 중앙, 캐릭터 띠 아래 |

시안이 바뀌면 이 표와 CSS의 mm 값을 함께 고쳐주세요.
앞면 디자인의 QR 자리(흰 둥근박스)는 QR의 quiet zone 역할을 하므로 **밝은 무지**로 유지해야 합니다.
